## Project

A responsive React and Vite frontend prototype for organizing witness descriptions into a forensic scene overview. It uses fictional demo content and does not connect to an AI service or process real case information.

## Run locally

Requires Node.js and npm.

```powershell
cd crime-scene-reconstruction
npm.cmd install
npm.cmd run dev
```

Open the local URL printed by Vite, usually `http://localhost:5173/`.

## Checks

```powershell
npm.cmd run lint
npm.cmd run build
```

Use **Load Demo** to preview a fictional incident. **Generate Scene** is a UI placeholder; scene generation is not connected yet. No API key is required.
